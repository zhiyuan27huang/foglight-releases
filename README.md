# Foglight

**Turn your course slides and notes into quiz levels you can actually review.**
把你的课件和笔记变成能闯关、能复习的题目。 [中文说明 ↓](#中文)

Foglight reads your PDF, PowerPoint or Word files (or a YouTube video with captions) and builds short quiz levels from them. Every question points back to the exact sentence it came from, so you can always check it against your own material. Cards you get wrong come back for review right before you'd forget them.

- **Free, no account.** You use your own AI key (free options available); your files are not sent to any Foglight server.
- **Windows and Mac** desktop app, English and Chinese interface.
- This repository only hosts the installers and the auto-update feed. The source code is private.

**In mainland China?** Windows installers are mirrored on Gitee, which is usually easier to reach: <https://gitee.com/zhiyuan27huang/foglight-releases/releases>. The Mac installer is too large for Gitee and is only available here.

## Install on Windows

1. Download the `_x64-setup.exe` file.
   If your browser says the file "isn't commonly downloaded" or could be harmful, choose **Keep** (in Edge: **…** → **Keep** → **Show more** → **Keep anyway**). Foglight is new and not code-signed yet, so Windows doesn't recognise it.
2. Double-click the installer. If a blue window says **"Windows protected your PC"**, click **More info** → **Run anyway**.
3. Follow the installer. Foglight appears in the Start menu.

## Install on Mac

**Requires a Mac with Apple Silicon (M1 or newer).** Intel Macs are not supported.
To check: Apple menu → About This Mac → "Chip" should say Apple M1/M2/M3/M4.

1. Download the file ending in `_aarch64.dmg`.
2. Open the downloaded `.dmg` and drag **Foglight** into the **Applications** folder.
3. Open **Applications** and double-click **Foglight**. macOS will block it the first time, because Foglight is not yet registered with Apple. Click **Done** (not "Move to Trash").
4. Open **System Settings → Privacy & Security**, scroll down to **Security**, and click **Open Anyway** next to the Foglight message. Confirm with your password or Touch ID.
5. Foglight opens. You only need to do steps 3–4 once.

### If it still won't open

- **On macOS 14 or older:** in Applications, right-click **Foglight** → **Open** → **Open**.
- **If macOS says "Foglight is damaged and can't be opened":** the app is not damaged. Open **Terminal**, paste this line, press Return, then open Foglight again:

      xattr -cr /Applications/Foglight.app

## First run: get a free AI key

Foglight uses an AI model to write questions, and you bring your own key. Any one of these is enough:

| Provider | Where to get a key | Good for |
|---|---|---|
| Groq | <https://console.groq.com/keys> | Outside China |
| Zhipu (智谱) | <https://open.bigmodel.cn> | Inside or outside China |
| DeepSeek | <https://platform.deepseek.com> | Inside China (low-cost, not free) |

Choose the provider in Foglight and paste the key (you can change it later in Settings). The key stays on your computer.

## Updates

You only install once. Foglight downloads new versions by itself while it is open, and you get the new version the next time you open it.

**Mac on 0.3.0 or earlier:** automatic updates failed on those versions. Install 0.3.1 once from the `.dmg` by hand; updates work after that.

## Privacy

- Your files and cards stay on your computer. Questions are generated by the AI provider you chose, using your key.
- Foglight sends an **anonymous usage count** (app version, platform, and counts such as how many cards you have and how many days you studied) so we can tell whether anyone uses it. There is no IP address column and no file content. It is on by default and you can turn it off in Settings.

## Windows 安装

1. 下载 `_x64-setup.exe`。
   浏览器提示「不常下载」或「可能有害」时，选**保留**（Edge：**…** → **保留** → **显示更多** → **仍然保留**）。Foglight 是新软件、还没有代码签名，所以 Windows 不认识它。
2. 双击安装包。如果出现蓝色的 **「Windows 已保护你的电脑」**，点 **更多信息** → **仍要运行**。
3. 按提示装完，开始菜单里就有 Foglight。

## Mac 安装

**需要 Apple 芯片（M1 及以后）的 Mac**，Intel 芯片的 Mac 不支持。
查看方法：左上角苹果菜单 → 关于本机 →「芯片」一栏写着 Apple M1/M2/M3/M4。

1. 下载 `_aarch64.dmg`。
2. 打开 `.dmg`，把 **Foglight** 拖进 **应用程序** 文件夹。
3. 在 **应用程序** 里双击 **Foglight**。第一次会被拦下（因为还没有在 Apple 登记），点 **完成**，不要点「移到废纸篓」。
4. 打开 **系统设置 → 隐私与安全性**，往下拉到 **安全性**，在 Foglight 那条提示旁点 **仍要打开**，用密码或触控 ID 确认。
5. Foglight 打开。第 3–4 步只需要做一次。

### 还是打不开

- **macOS 14 及更早：** 在应用程序里右键 **Foglight** → **打开** → **打开**。
- **提示「Foglight 已损坏，无法打开」：** 软件没有坏。打开 **终端**，粘贴下面这行回车，再打开 Foglight：

      xattr -cr /Applications/Foglight.app

## 第一次使用：准备一个免费 AI key

Foglight 用 AI 出题，需要你自己的 key。下面任选一个就够：

| 服务 | 申请地址 | 适合 |
|---|---|---|
| 智谱 | <https://open.bigmodel.cn> | 国内外都能用 |
| DeepSeek | <https://platform.deepseek.com> | 国内（很便宜，但不免费） |

在 Foglight 里选好服务、粘贴 key（之后可以在设置里改）。key 只保存在你自己的电脑上。

## 更新

只需要装一次。Foglight 打开时会自己下载新版本，下次打开就是新版。

**Mac 上 0.3.0 及更早的版本：** 这些版本的自动更新会失败，需要从 `.dmg` 手动装一次 0.3.1，之后就能正常自动更新。

## 隐私

- 你的文件和卡片都留在你自己的电脑上；题目由你选的 AI 服务用你的 key 生成。
- Foglight 会发送**匿名使用统计**（版本、系统，以及卡片数、学习天数这类计数），只用来了解有没有人在用。表里没有 IP 这一列，也不含文件内容。默认开启，可以在设置里关闭。
